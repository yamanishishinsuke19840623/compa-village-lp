【2026-08-19 更新⑤】ゆうさんが自分で「予約不可」に設定できる、
Booking.comの管理画面のような日程ブロック機能を追加しました。
・予約台帳スプレッドシートのメニューに「📅 空室ブロック管理」を新設
・押すと右側にサイドバーが開き、日程・部屋タイプ・台数・メモを入力してブロック/解除できる
・仕組みは「（オーナーブロック）」という名前の仮予約行を台帳に追加するだけで、
  既存の空室判定（isAvailable/getBookedRanges）にそのまま乗る設計。
  LP側・isAvailable()・getBookedRanges()のロジックは一切変更していない
・新規ファイル BlockSidebar.html が追加されたので、デプロイ時はCode.gsだけでなく
  このHTMLファイルもApps Scriptプロジェクトに追加する必要あり（下記STEP2参照）
・新ステータス「オーナーブロック」を追加（H列プルダウンにも反映。
  既存の稼働中シートには自動反映されないため、初回だけ関数選択で
  「addBlockStatusToValidation」を選んで実行するとプルダウンにも追加される。
  ※プルダウンに無くてもスクリプトからの書き込みには支障なし）
・使い方はゆうさん向けマニュアルに追記済み（予約サイトの流れ・使い方マニュアル_ゆうさん用.txt STEP4）

【2026-08-15 更新④】Stripe Webhookで決済完了時にお名前・メールを自動取得するようにしました。
・doPost冒頭で `?wh=シークレットトークン` を照合し、一致すればStripeのWebhookとして
  handleStripeWebhook_(e) に処理を渡す（既存のLP予約ロジックとは完全に別分岐）
・STRIPE_WEBHOOK_SECRET定数を新設（値: 2922dae4fb4470280cb48a0ace5778231f81d463c94879e0）
・logPendingPayment(d)が10列目にrefId（LP側で生成する一意な参照ID）を書き込むように変更
・findRowByRefId_(refId)でrefId一致行を検索し、Stripeのcheckout.session.completedイベントから
  お名前・メールを取得して該当行に書き込み、ステータスを自動で「確定」にする
・確定時はsendPaymentConfirmedNotification_で実名入りメールをホストへ送信

再デプロイ後、やまちゃんはGASのWebアプリURLの末尾に
`?wh=2922dae4fb4470280cb48a0ace5778231f81d463c94879e0` を付けたURLを
ゆうさんに送り、Stripeダッシュボードのwebhook設定に登録してもらう
（手順は「Stripe手順書_ゆうさん用.txt」STEP7参照）。
STEP6（Payment Linkで氏名収集をON）もゆうさんの作業として必要。

※ GAS doPost(e)はStripe-Signatureヘッダーを読み取れない制約があるため、
  標準的な署名検証はできない。URLクエリの`?wh=`トークン照合で簡易的に認証している。
  このURLはページのソースには出てこない（Stripeダッシュボードにのみ登録する）ので、
  index.html内のGAS_BOOKING_ENDPOINTより秘匿性は高いが、絶対に外部に漏らさないこと。

【2026-08-13 更新③】スタンダード/ドミトリーが直接Stripe決済へ進む方式に変わったことで、
GASに記録が残らず空室表示が更新されない問題を修正しました。
「予約に進む」を押した瞬間に、名前・メール不要の「仮予約」を予約台帳に記録するようにし、
以下を追加しています：
・doPost が kind:'stripe_pending' を受け付ける（名前・メール不要）
・ステータス「決済へ進行中」を新設（setupSheetのプルダウンにも追加）
・ホストへの軽い通知メール（sendPendingPaymentNotification）
・カスタムメニューに以下の2項目を追加：
   「💳 選択行を『決済確認済み』にする（メール送信なし）」
   　→ Stripeで実際の入金を確認できたら押す。ステータスが「確定」になるだけ
   「🗑 選択行の決済保留を解除する（メール送信なし）」
   　→ 決済が完了せず放置された仮予約を空室に戻す
下記と同じ手順で、最新のCode.gsを貼り直して再デプロイしてください。
※ 使い方の全体像は「予約サイトの流れ・使い方マニュアル_ゆうさん用.txt」も参照

作業時間：約10分

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 1　Google Apps Script を開く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ブラウザで以下を開く:
  https://script.google.com

「新しいプロジェクト」をクリック


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 2　コードを貼り付ける
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 左側のファイル欄に「コード.gs」が表示されている
2. その中身を全部削除する
3. 「Code.gs」（このフォルダの中）の中身を全コピーして貼り付ける
4. 左側のファイル欄の「＋」→「HTML」を選び、ファイル名を
   「BlockSidebar」（拡張子.htmlは自動で付くので入力不要）にする
5. 「BlockSidebar.html」（このフォルダの中）の中身を全コピーして貼り付ける
6. Ctrl+S で保存（プロジェクト名は「COMPA VILLAGE 予約管理」などにする）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 3　台帳スプレッドシートを作る（初回のみ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 上部の関数選択プルダウンで「setupSheet」を選ぶ
2. 「実行」ボタン（▷）をクリック
3. 初回は権限確認が出るので「権限を確認」→ Googleアカウントを選択
   →「詳細」→「（安全ではないページ）に移動」→「許可」
4. 下部の「実行ログ」に以下が表示される：

     Sheet ID: 1AbCdEfGhIjKlMnOpQrStUvWxYz...
     Sheet URL: https://docs.google.com/spreadsheets/d/...

   ★ この Sheet ID をコピーしておく ★

5. コード冒頭の以下の行に貼り付けて、再度 Ctrl+S で保存：

     var SHEET_ID = ''; ← ここにSTEP3でコピーしたIDを貼る


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 4　ウェブアプリとしてデプロイする
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 右上の「デプロイ」ボタン → 「新しいデプロイ」をクリック
2. 「種類の選択」→「ウェブアプリ」を選択
3. 以下のように設定する:

   ┌─────────────────────────────────┐
   │ 次のユーザーとして実行：自分（自分のGmailアドレス） │
   │ アクセスできるユーザー：全員                      │
   └─────────────────────────────────┘

4. 「デプロイ」ボタンをクリック
5. 権限の確認画面が出たら STEP3と同様に許可する

6. デプロイ完了！「ウェブアプリの URL」が表示される
   例：
     https://script.google.com/macros/s/AKfy.../exec

   ★ この URL をコピーしておく ★


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 5　LP の HTML に URL を設定する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

index.html の以下の行を探して URL を貼り付ける:

  var GAS_BOOKING_ENDPOINT = 'YOUR_GAS_ENDPOINT_HERE';
                              ↑ ここをSTEP4でコピーしたURLに差し替え

その後、git add → commit → push してデプロイ完了。

  STEP 6　動作確認
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

公開LPの「直接予約」セクションで日程を選び、テスト予約リクエストを送信して:

  ① 予約者のメールに「リクエストを受け付けました」メールが届く
  ② jannenenenene@gmail.com に通知が届く
  ③ やまちゃんの Gmail にも CC で届く
  ④ 台帳スプレッドシートに行が追加される
  ⑤ 同じ日程・同じ部屋タイプで再度予約しようとすると
     「満室」扱いになり、予約リクエストできない

以上で完了！

  予約の確定について
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

スプレッドシートを開くと、上部メニューに
「🌵 COMPA予約」というカスタムメニューが追加されています。

  1. 対応したい予約の行をクリック（どのセルでもOK）
  2. OKなら「🌵 COMPA予約」→「選択行を『確定』にして確定メールを送信」
     → お客様に確定メール（決済リンク付き）が自動送信され、
       ステータス列が「確定」に変わります
  3. NGなら「🌵 COMPA予約」→「選択行を『お断り』にしてお詫びメールを送信」
     → お客様にお詫びメールが自動送信され、
       ステータス列が「キャンセル」に変わります
     （2026-08-13追加：一棟貸しプランのように事前確認が必要なプランで、
       お断りする場合に手作業でメールを書かなくて済むようにしました）
